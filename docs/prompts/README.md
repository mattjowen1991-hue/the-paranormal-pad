# Session prompts

Copy-and-paste prompts for Claude Code, started in `~/projects/the-paranormal-pad`.
Each is also pinned as a card in the **Session Prompts** column of the board
(https://github.com/users/mattjowen1991-hue/projects/5). These files are the originals:
after editing one, run `python3 tools/sync_prompts.py` to update its card.

| Prompt | When |
|---|---|
| `publish-report.md` | A New report card is in **Ready** - build it on a branch and put it in Review |
| `publish-tape.md` | A New tape card is in **Ready** |
| `go-live.md` | You've checked a report/tape preview - merge, check live, move to **Live** |
| `create-ticket.md` | Scope a new website feature, fix or maintenance job |
| `open-ticket.md` | Work on a site ticket |
| `close-ticket.md` | Ship an approved site ticket and tidy the docs |
| `site-health-check.md` | Every month or two: check pages, videos, services, domain |

Drafting reports happens outside Claude Code, in the claude.ai Project - see `claude-project/README.md`.
